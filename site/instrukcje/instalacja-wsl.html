INSTRUKCJA ŚRODOWISKA / WINDOWS

Instalacja WSL
i Ubuntu

Przygotuj na prywatnym komputerze terminal Linux potrzebny do wykonywania skryptów Bash. Instrukcja prowadzi od sprawdzenia Windows aż do pierwszego działającego terminala Ubuntu.

SYSTEMWINDOWS 10 / 11ŚRODOWISKOWSL 2 / UBUNTU
00

ZANIM ZACZNIESZ

Sprawdź wymagania

Do instalacji potrzebujesz komputera z 64-bitowym Windows 11 albo aktualnym Windows 10, połączenia z internetem oraz konta pozwalającego zatwierdzić zmiany administratora. Standardowe polecenie instalacyjne działa w Windows 10 w wersji 2004 (kompilacja 19041) lub nowszej oraz w Windows 11.

  1. Zapisz otwarte dokumenty — instalacja może wymagać ponownego uruchomienia komputera.
  2. Uruchom Ustawienia → System → Informacje i sprawdź edycję oraz wersję Windows.
  3. Uruchom Windows Update i zainstaluj oczekujące aktualizacje systemowe.
  4. Nie wykonuj tej instrukcji na komputerze zarządzanym przez szkołę lub pracodawcę bez zgody administratora.
macOS i Linux

WSL jest składnikiem Windows. Na macOS lub Linuksie nie instaluj WSL — system ma już terminal zgodny z większością poleceń Bash używanych na zajęciach.

01

KONTROLA

Sprawdź, czy WSL już działa

Otwórz menu Start, wpisz PowerShell i uruchom aplikację. Na tym etapie nie musisz jeszcze wybierać opcji administratora. Wpisz:

wsl --status
wsl --list --verbose

Możliwe wyniki:

WynikCo zrobić
Na liście jest UbuntuWSL jest gotowy. Przejdź do sekcji 05.
WSL działa, ale nie ma UbuntuPrzejdź do sekcji 03 i doinstaluj dystrybucję.
Polecenie nie jest rozpoznawane lub WSL nie jest zainstalowanyWykonaj instalację z sekcji 02.
02

INSTALACJA WSL

Włącz WSL i zainstaluj Ubuntu

Zamknij zwykłe okno PowerShell. Otwórz menu Start, wpisz PowerShell, kliknij wynik prawym przyciskiem i wybierz Uruchom jako administrator. Zatwierdź pytanie systemu, a następnie wykonaj:

wsl --install -d Ubuntu

Polecenie włącza potrzebne składniki Windows, instaluje WSL oraz pobiera Ubuntu. Nie zamykaj okna podczas instalacji. Jeżeli system poprosi o restart, wykonaj go.

Nie używaj przypadkowych instalatorów

Korzystaj z polecenia systemowego albo Microsoft Store. Nie pobieraj obrazów Ubuntu i instalatorów WSL z nieznanych stron.

03

TYLKO BRAKUJĄCE UBUNTU

Doinstaluj dystrybucję

Jeżeli WSL już działa, ale nie masz Ubuntu, otwórz PowerShell i sprawdź dostępne nazwy:

wsl --list --online

Następnie zainstaluj Ubuntu:

wsl --install -d Ubuntu

Możesz również wybrać wersję widoczną na liście, na przykład Ubuntu-24.04. W kolejnych poleceniach używaj dokładnie tej nazwy, którą pokazuje wsl --list --verbose.

04

PIERWSZE URUCHOMIENIE

Utwórz użytkownika Ubuntu

Po instalacji Ubuntu może uruchomić się automatycznie. Jeżeli tak się nie stanie, otwórz PowerShell i wykonaj:

wsl -d Ubuntu

Przy pierwszym uruchomieniu poczekaj na rozpakowanie systemu, a następnie podaj:

  1. Enter new UNIX username — wpisz prostą nazwę użytkownika, najlepiej małymi literami i bez spacji.
  2. New password — ustaw hasło użytkownika Ubuntu.
  3. Retype new password — wpisz to samo hasło ponownie.
Hasła nie widać

Podczas wpisywania hasła terminal nie wyświetla liter, kropek ani gwiazdek. Klawiatura działa — wpisz hasło i naciśnij Enter. To hasło może być potrzebne przy poleceniach sudo.

Jeżeli zainstalowałeś wersję o innej nazwie, uruchom ją na przykład przez wsl -d Ubuntu-24.04.

05

KONFIGURACJA

Ustaw Ubuntu i WSL 2 jako domyślne

W terminalu Ubuntu wpisz exit, aby wrócić do PowerShella. Następnie wykonaj:

wsl --set-default-version 2
wsl --set-default Ubuntu
wsl --list --verbose

Na liście gwiazdka * powinna znajdować się przy Ubuntu, a kolumna VERSION powinna zawierać 2. Jeżeli dystrybucja ma inną nazwę, podstaw ją do polecenia wsl --set-default.

Jeżeli Ubuntu widnieje jako WSL 1, przestaw istniejącą dystrybucję:

wsl --set-version Ubuntu 2

Konwersja może potrwać kilka minut. Nie wyłączaj komputera podczas tej operacji.

06

AKTUALIZACJA

Zaktualizuj Ubuntu

Uruchom domyślną dystrybucję poleceniem wsl. Poniższe komendy wykonuj już w terminalu Ubuntu:

sudo apt update
sudo apt upgrade -y

sudo uruchamia polecenie z uprawnieniami administratora Ubuntu i może poprosić o utworzone wcześniej hasło. apt update odświeża listę pakietów, a apt upgrade -y instaluje dostępne aktualizacje.

Sprawdź podstawowe narzędzia:

git --version
bash --version

Jeżeli Git nie jest dostępny, zainstaluj go:

sudo apt install -y git
07

WERYFIKACJA

Sprawdź gotowe środowisko

W PowerShellu wykonaj:

wsl --status
wsl --list --verbose
wsl

Po przejściu do Ubuntu wykonaj:

whoami
cat /etc/os-release
pwd
git --version
bash --version
  • Ubuntu jest widoczne na liście dystrybucji WSL.
  • Gwiazdka wskazuje Ubuntu jako dystrybucję domyślną.
  • Ubuntu korzysta z WSL 2.
  • Polecenie wsl otwiera terminal Ubuntu.
  • git i bash wyświetlają numery wersji.
08

ROZWIĄZYWANIE PROBLEMÓW

Gdy instalacja nie działa

wsl --install nie jest rozpoznawane

Uruchom Windows Update i sprawdź wersję systemu. Standardowe polecenie wymaga Windows 10 w wersji 2004 z kompilacją 19041 lub nowszą albo Windows 11. Dla starszego systemu skorzystaj z oficjalnej instrukcji instalacji ręcznej.

Instalacja zatrzymuje się na 0,0%

Sprawdź połączenie z internetem, uruchom ponownie komputer i ponów polecenie w PowerShellu uruchomionym jako administrator. Możesz też zainstalować aplikację Ubuntu z Microsoft Store.

Pojawia się błąd dotyczący Virtual Machine Platform lub wirtualizacji

Upewnij się, że komputer został ponownie uruchomiony po instalacji. Jeżeli problem pozostaje, sprawdź w Menedżerze zadań, w zakładce Wydajność → Procesor, czy wirtualizacja jest włączona. Zmiana ustawień BIOS/UEFI zależy od producenta komputera — skorzystaj z jego dokumentacji.

Nie pamiętam hasła użytkownika Ubuntu

Hasło Ubuntu jest niezależne od hasła i PIN-u Windows. Nie próbuj wielokrotnie zgadywać. Skorzystaj z oficjalnej dokumentacji WSL dotyczącej resetowania hasła dystrybucji.

PowerShell pokazuje inną nazwę niż Ubuntu

Skopiuj dokładną nazwę z wsl --list --verbose. Jeżeli jest to na przykład Ubuntu-24.04, używaj tej nazwy w poleceniach wsl -d, wsl --set-default i wsl --set-version.
